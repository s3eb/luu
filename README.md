# Luu Programming Language (لغة لُو)

Luu is an Arabic-script programming language transpiler built in Rust that targets Lua runtime.

## Overview
- **Extension:** `.luu`
- **Target:** Lua 5.1+

## Features
- Fully Arabic control structures and logic primitives.
- First-class error handling with native primitives (`مدفع`, `مدفع_ضاغط`, `خطأْ`, `أجزم`).
- VS Code integration and tooling support.
